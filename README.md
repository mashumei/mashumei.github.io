## 二、本地预览（两种方式）

**方式 A：直接打开**
双击 `index.html` 即可在浏览器查看（手机模式可用浏览器开发者工具切换）。

**方式 B：本地服务器（推荐，链接更真实）**
在本目录打开终端，运行：
```
python -m http.server 8080
```
然后浏览器访问 `http://127.0.0.1:8080/`。
（当前已为你启动在 8080 端口。）

## 五、如何新增文章（推荐流程）

> 网站的「内容中心」和「个人成长」4 个栏目页，全部由 `content.json` 自动生成——**加文章不需要改 HTML**。当前 8 篇均为公众号真实文章。

**加一篇公众号文章**

1. 打开 `content.json`，在 `"articles"` 数组里加一条：

```json
{
  "title": "文章标题",
  "url": "https://mp.weixin.qq.com/s/xxxxxxxx",
  "date": "2026-10-12",
  "topics": ["body"]
}
```

2. `topics` 表示文章属于哪个栏目，可以填多个：

| 取值 | 对应栏目 |
|---|---|
| `body` | 晨跑与身体管理 |
| `women` | 40+ 女性的自我成长 |
| `business` | 创业者的真实思考 |
| `ai` | AI 时代的学习与实践 |

3. 运行一次生成脚本：

```
python build_articles.py
```

它会自动完成三件事：刷新 `topics/*.html` 四个栏目页、刷新首页「内容中心」三组文章、把首页 4 张成长卡片的「查看全部 N 篇」改成实际数量。

4. 打开 GitHub Desktop → 提交 → 点 **Push origin**，线上约 1–2 分钟生效。

**新增一个栏目**（比如以后加「家庭教育」）：在 `content.json` 的 `"topics"` 里加一项（`id` / `name` / `tag` / `desc`），重跑脚本就会多生成一个栏目页；再把 `index.html` 里对应 `<a class="cat" href="topics/xxx.html">` 指过去即可。

**想挂站内长文**：`url` 也可以填站内路径（如 `articles/ai-growth-01.html`），效果一样，只是点击不跳公众号。

**公众号入口**：`content.json` 顶部的 `account.home` 是「去公众号看全部文章」按钮的地址（当前为该账号历史消息页），如需更换只改这一处。

## 六、免费 / 低成本发布上线

> 本环境当前无公网发布工具，以下为推荐方案，均无需购买服务器。
> **已确定首选 GitHub Pages**，完整「照着做就能上线」步骤见同目录 **DEPLOY.md**（含 GitHub Desktop 图形方案 + 命令行方案 + 微信打开注意事项）。

- **GitHub Pages（免费，国际访问）**：把整个文件夹推到 GitHub 仓库，开启 Pages 即可获得 `https://用户名.github.io/仓库名/` 链接，微信里可直接打开。
- **国内静态托管（低成本）**：如 Gitee Pages、Cloudflare Pages、Vercel，或国内云厂商的静态网站托管（部分有免费额度）。
- **国内自定义域名（最稳）**：买域名 + 国内静态托管 + ICP 备案（个人备案免费，约 1–2 周），微信里绝对畅通、最显专业。
- **国内自定义域名 + 备案**：若要用自己的域名（如 `hongyang.cn`），需：
  1. 在国内服务商购买域名；
  2. 完成 **ICP 备案**（个人备案通常免费，周期约 1–2 周，需身份证与实名）；
  3. 将域名解析到托管平台。
  备案是国内的合规要求，未备案域名在国内无法正常访问。

**发布前请注意**
- 不要将任何密钥、密码、个人敏感信息写进公开代码。
- 本网站不承诺"保证获客 / 保证排名 / 保证 AI 推荐"，文案已按此原则撰写，新增内容请保持同一口径。
- 涉及真实客户案例、评价、业绩数据前，务必获得对方授权，不虚构。
